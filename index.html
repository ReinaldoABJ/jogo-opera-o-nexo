📖 Manual Lógico do Comandante (Tabela-Verdade)

🟢 Operador E (AND / &&):

Ambas as condições devem ser verdadeiras para o drone entrar em ação. Se uma falhar, o resultado é Falso.

🟡 Operador OU (OR / ||):

Se pelo menos uma das condições for verdadeira, a manobra já é autorizada.

🔴 Operador NÃO (NOT / !):

Inverte a condição. Por exemplo: NOT(GÁS_TÓXICO) é Verdadeiro quando NÃO há gás tóxico no local.

🔵 Operador XOR (OU Exclusivo):

Apenas uma das condições pode ser verdadeira, nunca ambas ao mesmo tempo.
