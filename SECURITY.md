# 🛡️ Política de Segurança (Security Policy)

## Versões Suportadas

Apenas a versão mais recente na branch `main` recebe atualizações de segurança e correções de integridade.

| Versão | Suportada          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reportando uma Vulnerabilidade

Agradecemos a colaboração da comunidade em manter o **Operação NEXO** e a plataforma **GameHub** seguros para todos os alunos e educadores.

Se você descobrir uma falha de segurança, vulnerabilidade de injeção ou brecha no sistema antifraude/telemetria:

1. **NÃO** abra uma Issue pública no GitHub descrevendo a vulnerabilidade.
2. Envie um e-mail com os detalhes técnicos e passos para reprodução para os mantenedores do projeto ou abra um **Security Advisory Privado** na aba "Security" deste repositório.
3. Inclua, se possível:
   - Descrição detalhada da vulnerabilidade.
   - Navegador, versão e sistema operacional testados.
   - Prova de conceito (PoC) ou passos de reprodução.
   - Impacto estimado.

---

## Compromisso de Resposta

- **Triagem inicial:** Até 48 horas úteis.
- **Correção:** Implementada com máxima prioridade e liberada via commit assinado e release note.
